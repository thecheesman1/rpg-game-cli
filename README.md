# RPG Game CLI

Welcome to the ultimate text-based RPG experience! This command-line interface game will transport you to a world of adventure, where your choices matter and your courage is tested.

## Features

- Text-based adventure gameplay
- Multiple character classes
- Interactive combat system
- Quests and exploration
- Save and load functionality

## Getting Started

1. Clone the repository
2. Install dependencies
3. Run the game with `python main.py`

## Controls

- Use arrow keys or WASD to move
- 'i' to open inventory
- 'q' to quit
